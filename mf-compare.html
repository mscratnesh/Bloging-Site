Compare mutual fund rolling returns

A fund's "3-year return" depends on the day you measure it. Rolling returns measure it from every day in the fund's history, so you see how the fund did for everyone who held it for three years, not just the lucky start date.

Add up to six funds, pick a holding period and compare the range of returns, how often each fund came out ahead and how hard each one fell. The SIP calculator shows what a monthly SIP in each fund would have become.

How to read itRolling, not point-to-point

What a rolling return is

For a 3-year rolling return, take every day in the fund's history, look back exactly three years and work out the yearly return (CAGR) over that stretch. Thousands of overlapping 3-year periods give a spread of outcomes instead of one number.

What to look for

A higher average is good, but so is a narrow range: a fund whose worst 5-year return was still positive treated its holders better than one with a higher average and some losing stretches. "How often it came out ahead" compares the funds on the same dates.

Keep it fair

Compare Direct Growth plans with each other, funds of the same type with each other, and use "Common period only" so every fund is measured over the same market. Most Direct plans start in January 2013.

QuestionsRolling returns explained
What are rolling returns in mutual funds?

Rolling returns are a fund's yearly returns (CAGR) over a fixed holding period, such as 3 years, measured from every day in its history instead of one start date. They show the full range of results investors actually got: the average, the best, the worst and how often the fund lost money.

How are rolling returns calculated?

For each NAV date, take the NAV on that date and the NAV exactly N years earlier, then work out the yearly return: (NAV today ÷ NAV N years ago) to the power 1/N, minus 1. Repeating this for every date gives thousands of overlapping N-year returns.

What is the difference between rolling returns and trailing returns?

A trailing (point-to-point) return measures one period ending today, so it changes a lot depending on where the market is right now. Rolling returns measure every period of the same length across the fund's history, so they show consistency and are a fairer way to compare funds.

Which rolling return period should I use?

Match it to how long you plan to hold. For equity funds, 3, 5 or 7-year rolling returns are the most useful; 1-year rolling returns are very noisy. Longer periods need more history, so they are only available for older funds.

Where does the NAV data come from and how current is it?

The daily NAVs are published by AMFI (Association of Mutual Funds in India) and fetched through mfapi.in. The tool refreshes them every night after midnight IST, so results include the previous trading day's NAV.
