What would a SIP in this fund have become?

Most SIP calculators assume a fixed return every year. This one uses the fund's actual NAV on every SIP date, so you see what a real monthly SIP would have become, with the market's ups and downs included.

How to read itReal NAVs, not an assumed return

How the SIP is worked out

On your SIP date each month, the instalment buys units at that day's NAV, or the next NAV if markets were shut. The units add up, and their value is shown on the latest date every chosen fund has a NAV.

What XIRR means

Each instalment is invested for a different length of time, so a simple "total gain" hides the real rate. XIRR is the single yearly return that turns every instalment into the final value, the way fund houses report SIP returns.

Keep it fair

Compare Direct Growth plans with each other and use a start month every fund existed in. A different start month or SIP date can change the result a lot.
